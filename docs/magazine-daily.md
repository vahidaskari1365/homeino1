# مجله و ترندهای روز هومینو — راهنمای گردش کار روزانه

هومینو باید «مرجع فارسی دیزاین خانه» باشد. این سند توضیح می‌دهد سیستم ترندها چطور
هر روز، خودکار، محتوای تازه و **اورجینال** تولید می‌کند.

## معماری

```
فیدهای RSS منابع معتبر (AD، Livingetc، Homes & Gardens، Ideal Home، Dwell،
Design Milk، Wallpaper، Surface + فیدهای پشتیبان Google News)
        │  هر روز ۰۷:۳۰ تهران (GitHub Actions cron)
        ▼
scripts/magazine-daily.mjs
  ۱. انتخاب مطالب تازه با امتیاز کلیدواژه (۳ روز گذشته، ضدتکرار با آرشیو)
  ۲. استخراج متن مطلب منبع (best-effort)
  ۳. تولید بریف فارسی با LLM طبق پرامپت قواعد سفت‌وسخت
  ۴. اعتبارسنجی + ادغام در src/content/trends/trends.json (نگه‌داری ۱۲۰ روز)
        ▼
سایت — همان فایل JSON به‌صورت استاتیک خوانده می‌شود:
  /trends            صفحه‌ی مرجع (آخرین روز + آرشیو)
  /trends/[date]     بریف‌های هر روز
  /feed.xml          RSS کل سایت (ترندها + مجله)
  sitemap            خودکار به‌روز می‌شود
```

## قواعد محتوا (ضدکپی)

- بریف‌ها **بازنویسی اختصاصی** هستند؛ ترجمه‌ی تحت‌اللفظی و کپی ممنوع است.
  پرامپت سیستم صراحتاً ترجمه‌ی مستقیم را منع می‌کند و فقط «واقعیت‌ها + ایده‌ها» را مجاز می‌داند.
- نام و لینک منبع اصلی همیشه کنار هر بریف نمایش داده می‌شود (`source` و `extraSources`).
- هر بریف یک بخش «برای خانه ایرانی» دارد که ارزش افزوده‌ی محلی است.
- تست‌های `src/lib/trends.test.ts` شکل داده را قفل می‌کنند (خلاصه‌ی کوتاه = شکست تست).

## راه‌اندازی در گیت‌هاب

۱. در Settings → Secrets and variables → Actions این سه Secret را بسازید
   (هر سرویس سازگار با `chat/completions`OpenAI کار می‌کند):
   - `LLM_API_KEY` — کلید سرویس
   - `LLM_BASE_URL` — مثل `https://api.openai.com/v1`
   - `LLM_MODEL` — اختیاری (پیش‌فرض `gpt-4o-mini`)

۲. ورک‌فلو `.github/workflows/magazine-daily.yml` هر روز ساعت ۰۴:۰۰ UTC
   (۰۷:۳۰ تهران) اجرا می‌شود؛ در صورت تغییر `trends.json`، با هویت
   `homeino-magazine-bot` کامیت و پوش می‌کند. اجرای دستی هم با
   `workflow_dispatch` ممکن است. بدون Secrets، ورک‌فلو سبز می‌ماند و چیزی
   تولید نمی‌کند.

۳. دپلوی (مثلاً Vercel) از کامیت جدید، build می‌گیرد و سایت همان روز
   به‌روز می‌شود.

## اجرای دستی (لوکال)

```bash
npm run magazine:daily
# با سرویس شخصی:
LLM_BASE_URL=https://api.openai.com/v1 LLM_API_KEY=sk-... LLM_MODEL=gpt-4o-mini npm run magazine:daily
```

در سندباکس توسعه، اگر سرویس خارجی تنظیم نشده باشد، از `z-ai-web-dev-sdk`
استفاده می‌شود.

## کاور تصاویر

کاورهای استخر `/public/images/trends/` (هشت تصویر تولیدی اختصاصی هومینو) بر
 اساس دسته‌ی هر بریف انتخاب می‌شوند — بدون وابستگی به سرویس خارجی و بدون ریسک
کپی‌رایت. برای بریف‌های ویژه می‌توانید مسیر `cover` را در `trends.json` دستی
عوض کنید.

## ویرایش دستی

`src/content/trends/trends.json` یک فایل معمولی است؛ می‌توانید بریف اضافه/حذف
 کنید یا متن‌ها را بهبود بدهید. فقط این قواعد را نگه دارید: `slug` یکتا،
`date` به شکل `YYYY-MM-DD`، `summary` بیش از ۱۵۰ کاراکتر، و دسته از فهرست
مجاز. تست‌ها همین‌ها را چک می‌کنند.
