# بازیاب: افزودن ایجنت روزانه جدید به هومینو

> الگوی اثبات‌شده از ایجنت‌های مجله و الهام (سبز و پایدار در تولید) + اصول
> agent-harness-construction و autonomous-loops از ECC v2.2.1.
> هر ایجنت جدیدی (جذب غرفه، پست اینستاگرام، گزارش رقبا، ایمیل بازگشت…) با این بازیاب در نیم‌روز ساخته می‌شود.

## ۱. طراحی هارنس (چهار رکن ECC)

- **فضای اکشن باریک**: ایجنت یک کار مشخص دارد («روزانه X مطلب تازه بسازد») — ابزار همه‌کاره نده
- **مشاهده‌پذیری**: خروجی هر اجرا ساختار ثابت: `status/summary/next_actions/artifacts`
- **بازیابی خطا**: هر مسیر شکست پیام فارسی ریشه دارد + تلاش امن بعدی (fallback زنجیره LLM)
- **بودجه کانتکست**: پرامت کوتاه و schema-first؛ خروجی JSON سخت‌گیرانه

## ۲. فایل‌هایی که می‌سازی

| فایل | نقش | الگو |
|---|---|---|
| `.github/workflows/<name>-daily.yml` | schedule ×۲-۳ نوبت + نوبت جبرانی + `workflow_dispatch` + concurrency group + `permissions` حداقلی | `magazine-daily.yml` |
| `scripts/<name>-daily.mjs` | منطق: چرخش/ماتریس → منبع (جستجو/LLM/دیتابیس) → dedupe → cap → نوشتن | `inspiration-daily.mjs` |
| `scripts/lib/<name>-pool.json` (اختیاری) | استخر منبع محدود (عکس/لینک) با شمارش مصرف‌نشده | `inspiration-pool.json` |
| ثبت در `scripts/watchdog.mjs` | چک تازگی جدید (مثلاً ≤ ۴۸ ساعت) تا خاموشی بی‌سروصدا آژیر شود | چک‌های موجود |
| (اختیاری) `scripts/expand-<name>-pool.py` | شارژ مجدد استخر از سندباکس، ذخیره تدریجی | `expand-inspiration-pool.py` |

## ۳. چک‌لیست ساخت (به ترتیب)

- [ ] **dedupe**: تکرار محتوا مطلقاً ممنوع — Set از id/url مصرف‌شده‌ها (`seenImgs` الگو)
- [ ] **سقف روزانه/ذخیره**: cap روی کل (مثلاً ۳۶۰ پین) و سقف هر اجرا (۶ آیتم)
- [ ] **لاگ اجرا**: `logContentAgentRun(ROOT, {...})` با `ok/added/poolRemaining` — پنل ادمین همین را می‌خواند
- [ ] **کامیت-اگر-تغییر**: `git status --porcelain` → کامیت → `pull --rebase` + ۳ تلاش پوش (تداخل دو بات)
- [ ] **تنوع نوبت**: cursor بر اساس `daySlot/runSlot` — هر نوبت محتوای متفاوت
- [ ] **گزارش صادقانه**: `ok:false` وقتی چیزی اضافه نشد + دلیل ریشه (استخر خالی/شبکه/کلید)
- [ ] **بدون secret در کد**: کلیدها فقط از `secrets.` یا `scripts/lib/llm-chain.mjs`
- [ ] تست محلی: `node scripts/<name>-daily.mjs --dry` سپس یک اجرای واقعی
- [ ] dispatch دستی اولین اجرا + چک لاگ اکشن‌ها + چک کامیت بات

## ۴. قرارداد رعایت‌شده در همه ایجنت‌ها

- بات با GITHUB_TOKEN داخلی پوش می‌کند — هرگز به توکن شخصی وابسته نباش (انقضا نمی‌تواند ایجنت را بکشد)
- ورک‌فلو سبز ≠ کارکرد: «کامیت بات در تاریخ ریپو» تنها اثبات انتشار است
- اگر منبع خارجی محدود است (عکس/لینک): استخر + `poolRemaining` + آستانه آلارم (۴۰)

## ۵. ایجنت‌های بعدی صف (اولویت کسب‌وکار)

1. **جذب غرفه** — روزی ۱۰ تولیدکننده کاندید از منابع فارسی → جدول + پیش‌نویس پیام → آلارم هفتگی آمار
2. **اینستاگرام اتومات** — روزی ۱ کاروسل از پین‌های برتر الهام (پرسونا، کپشن فارسی، ساعت طلایی)
3. **گزارش رقبا هفتگی** — اسکرپ قیمت/کالای رقبای ایرانی → بریف مدیر
