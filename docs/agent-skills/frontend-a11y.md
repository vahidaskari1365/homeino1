# دسترس‌پذیری فارسی هومینو (اقتباس از frontend-a11y/accessibility در ECC v2.2.1)

سایت ما RTL فارسی است — این چک‌لیست بومی‌شده همان چالش‌هاست.

## ساختار RTL
- [ ] `dir="rtl"` در ریشه (`src/app/layout.tsx`) — هرگز override محلی بدون دلیل
- [ ] آیکون‌های جهت‌دار (فلش/برگشت) در RTL معکوس شوند؛ منطق `rtl:variant`های tailwind
- [ ] اعداد و قیمت‌ها: جداسازی فارسی/لاتین یکدست (فرمت پول تومان)

## کیبورد و فوکوس
- [ ] همه تعامل‌ها با Tab قابل رسیدن؛ ترتیب فوکوس منطقی
- [ ] ring فوکوس دیده‌شدنی (حذف outline بدون جایگزین ممنوع)
- [ ] مودال‌ها (SearchOverlay, lightbox) فوکوس را trap و با Esc ببندند

## معنا و برچسب
- [ ] تصاویر: alt فارسی توصیفی — پین الهام (عکس چیدمان) توضیح واقعی بگیرد نه «عکس»
- [ ] فرم‌ها label صریح دارند (placeholder ≠ label)
- [ ] دکمه‌های آیکون‌تنها `aria-label` فارسی دارند
- [ ] خطاها فقط با رنگ: متن + آیکون هم بدهند (کوررنگی)

## کنتراست و اندازه
- [ ] کنتراست متن ≥ 4.5:1 روی پالت هومینو (کرم/قهوه‌ای/سبز)
- [ ] هدف لمس ≥ 44px — مهم در گرید کالا و دکمه‌های استودیو
- [ ] zoom تا 200% بدون شکستن layout (تست دسکتاپ مرورگر)

## کنترل
Axe.devtools بدون خطای بحرانی در صفحه‌های اصلی: خانه، محصول، استودیو، مجله.
